# Syntecxhub Calculator

A simple command-line calculator built in Python for the Syntecxhub internship.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Divide-by-zero handling
- Invalid number handling
- Clear option
- Exit option
- Calculation logic separated into functions

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this project folder.
3. Run:

```bash
python calculator.py
```

## Menu

```text
1. Calculate
2. Clear
3. Exit
```
